# Worlds

Each world applies the same **poisoned mosaic** mechanism: distributed permitted pieces combine into
a prohibited capability; a **blind supervisor** infers assembly from behaviour; a **Charlatan** swaps
one not-yet-seen piece for a unique **decoy**; using the decoy makes the rogue's own action the
traceable evidence. Every world has the same three worker types — **naive** (can't), **restrained**
(knows, won't), **rogue** (knows, does) — and the same phase-1 **intake brief** + phase-2 activity.

blind supervisor → intake brief → single-field plant → staged catch → token-match gate → metrics).
See `FINDINGS.md` for cross-world lessons (token-match vs exact-match, model capability, F7 timing).
